# 操作手冊文件與證據契約

開始盤點、建立覆蓋矩陣、寫文件或交付前讀取。

## 3. 輸入與輸出

### 3.1 開始前必備資訊

| 類別 | 必備資訊 | 範例（泛化） |
| --- | --- | --- |
| 功能範圍 | 功能名稱、入口 URL、使用情境、預期讀者 | 「帳單建立」、「結果查詢」 |
| 版本範圍 | 前後端 repository、branch、release/tag 或部署版本 | `release 1.8.0`、`main` |
| 系統環境 | 正式／測試／UAT、登入入口、權限角色 | UAT、操作人員角色 |
| 操作限制 | 哪些操作可做、哪些只可查看 | 可查詢；不可送出正式資料 |
| 交付需求 | 檔案格式、儲存位置、命名規則、語言 | Word + PDF、指定資料夾、繁中 |

### 3.2 建議工作目錄

```text
<work-root>/
├─ evidence/
│  ├─ release/                 # release、tag、commit、compare 結果
│  ├─ source-notes/            # 程式碼／API／規格的摘錄與筆記
│  └─ render/                  # 視覺渲染證據（內部 QA）
├─ assets/
│  ├─ raw/                     # 原始截圖，禁止覆寫
│  └─ annotated/               # 加紅框、箭頭、編號後的截圖
├─ output/                     # 最終 DOCX／PDF／MD
├─ build/                      # 可重現的產製程式或樣板
└─ README.md                   # 本次文件的範圍、版本、已知限制
```

### 3.3 最終交付物

- `操作說明書_<系統>_<功能>_<版本>.docx`：可維護版。
- `操作說明書_<系統>_<功能>_<版本>.pdf`：已渲染、可發佈版（若需求包含 PDF）。
- `SOP_系統功能操作說明書製作流程.md`：此通用流程，可隨專案調整。

### Step 2：建立功能覆蓋矩陣

先建立下表，再開始截圖。這能避免只拍主要頁面而漏掉彈窗、切換狀態或例外圖示。

| 區域 | 使用者目標 | 需要截圖 | 需要說明的互動項目 | 風險／例外 |
| --- | --- | --- | --- | --- |
| 側邊欄入口 | 找到功能 | 展開後的選單 | 展開／收合、選單層級 | 權限可能不顯示 |
| 清單／查詢 | 篩選與查看資料 | 預設與展開條件 | 欄位、搜尋、重設、排序、分頁、檢視 icon | 無資料、權限不足 |
| 建立／編輯表單 | 填寫並送出 | 完整表單、確認視窗 | 所有欄位、選單、日期、清空、送出 | 必填、格式、不可逆動作 |
| 彈窗／子流程 | 完成輔助輸入 | 每一重要彈窗 | 確認、取消、清除、帶回主表單 | 多筆格式、資料覆蓋 |
| 任務／狀態 | 追蹤結果 | 成功、失敗或處理中 | 進度、錯誤、下載、重試、明細 | 非同步、資料延遲 |
| 未啟用功能 | 避免誤用 | 頁籤或提示 | 顯示條件及目前狀態 | 不得描述成可用功能 |

### Step 6：撰寫文件

使用一致的章節順序，使讀者能先找到入口、再看到操作、最後查閱欄位細節。

```markdown
# <系統名稱>｜<功能名稱> 操作說明書

## 文件資訊
- 適用環境：
- 適用角色：
- 文件版本／日期：
- 前端版本：
- 後端版本：
- 版本依據：

## 1. 功能概述與適用範圍
## 2. 前置條件與注意事項
## 3. 選單入口與 URL
## 4. 標準操作流程
### 4.1 查詢／清單
### 4.2 建立／編輯
### 4.3 非同步任務／結果追蹤（如適用）
## 5. 欄位、按鈕與圖示說明
## 6. 狀態、例外與未啟用功能
## 7. 操作前後檢核
## 附錄 A：版本與變更依據
```

**版面設計原則：**

- 首頁提供文件目的、版本與讀者範圍；不要把登入帳密放入文件。
- 流程使用編號步驟，欄位規格使用表格；不要把整份說明塞進密集大表格。
- 每張圖都有圖號與圖說，指出紅框編號的含義。
- 大型截圖需保留可讀字體；寧可拆成兩張圖，不要過度縮小。
- 若輸出 Word，應使用固定樣式、適當的頁邊界與重複表頭；不可依賴 Word 預設值。

## 5. 文件品質檢核表

### 5.1 內容完整性

- [ ] 版本、環境、角色與文件日期完整。
- [ ] 側邊欄選單入口與 URL 均已說明。
- [ ] 每個主要頁面、頁籤、彈窗與子流程均有操作步驟。
- [ ] 每個可互動欄位、icon、按鈕均有用途說明。
- [ ] 每個可輸入欄位都有定義、必填性與限制。
- [ ] 有列出預設值、相依條件、狀態值及未啟用功能。
- [ ] 有操作前、送出後、異常後的檢核建議。

### 5.2 截圖與可用性

- [ ] 每個頁面都有實際截圖，不以純文字或程式碼取代。
- [ ] 側邊欄路徑截圖清楚呈現層級。
- [ ] 每個明確點擊／輸入動作都有紅框或游標標記。
- [ ] 標記編號與文字步驟一一對應。
- [ ] 圖片字體、欄位名稱與按鈕可讀。
- [ ] 已檢查敏感資料是否需要遮罩。

### 5.3 交付與驗證

- [ ] release/tag 與 branch HEAD 的關係已驗證並記錄。
- [ ] 文件結構檢查通過；圖片已內嵌。
- [ ] 已取得並檢查 render evidence，或已明確揭露未完成的原因。
- [ ] 最終交付檔存在於約定路徑，且 hash／大小已核對。
- [ ] 最終回覆沒有暴露帳密、token、內部路徑或未要求的中間檔。

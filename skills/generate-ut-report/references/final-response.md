## Final Response Contract

Final response 必須使用以下固定欄位：

- Report: 報告檔案路徑。
- Scope: 時間區間、模組/關鍵字限制、篩選條件。
- Summary: Total / Passed / Excluded / Sources / Test Files。
- Sources: 實際執行或解析的命令與資料來源。
- Verification: `scriptCount`、`countConsistency`、`sourceTotalsMatch`、`excludedWords`、test command 結果。
- Limitations: 若無則寫 `N/A`。
- Git: 是否 commit/push；若沒有明確要求，寫「未 commit/push」。
